# ГРАНЬ — отделка квартир в Санкт-Петербурге

Лендинг с проектами, услугами, этапами работы и контактами.

## Запуск

Нужен Node.js. Зависимостей нет.

```sh
npm start
```

Откройте http://127.0.0.1:5187. Проверка синтаксиса: `npm run check`.

## Файлы

- `outputs/index.html` — страница.
- `outputs/workshop.css` — стили.
- `outputs/workshop.js` — взаимодействия и анимации.
- `outputs/assets/` — фотографии.
- `outputs/dev-server.cjs` — локальный сервер и API отзывов.

## Публикация

Статические файлы сайта находятся в `outputs`. Отзывы используют `/api/reviews`: сервер сохраняет их в локальный `outputs/reviews.json`, который не включается в Git. Путь можно изменить через `REVIEWS_FILE`.

GitHub Pages не запускает этот API. Для полной работы отзывов на публичном сайте нужен сервер с постоянным хранилищем или отдельный API с базой данных. Не следует публиковать локальный сервер как статический файл.

Фотографии интерьеров используются как демонстрационные; ссылка на Unsplash указана в подвале сайта.
